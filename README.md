# Code_In_Python 🐍

A collection of Python programs I've written while learning and practicing the language, from basic concepts to small projects.

## 📚 What's Inside

| Folder / File | Description |
|---------------|-------------|
| `basics/` | Variables, data types, operators, input/output |
| `control_flow/` | Conditionals and loops |
| `functions/` | Functions, recursion, lambda |
| `data_structures/` | Lists, tuples, sets, dictionaries |
| `patterns/` | Pattern-printing programs |
| `projects/` | Small beginner projects |


## 🚀 Getting Started

### Prerequisites
- Python 3.8 or higher ([download](https://www.python.org/downloads/))

### Clone the repository
```bash
git clone https://github.com/CoderAalok/Code_In_Python.git
cd Code_In_Python
```

### Run a program
```bash
python path/to/script.py
```
